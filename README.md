# CareShift 事业所排班演示

单个小規模多機能型居宅介護事业所的网页原型，支持中文和日文。

[在线演示](https://llvera.github.io/careshift2/)

## 本地演示

下载并解压仓库，在项目文件夹的终端输入：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Windows 也可使用 `py -m http.server 4173 --bind 127.0.0.1`。
浏览器访问 http://127.0.0.1:4173/，保持终端运行。

## 输入与操作

- 员工页支持添加、编辑、删除职员，使用四位数工号。
- 右上角选择月份和中文／日本語。
- 兼职及司机点击“当月可出勤”，逐日登记日期和时间范围。未登记日期不自动安排。每周模板仅用于批量预填，可再逐日修改。
- 兼职班次为2～9小时；可出勤范围可超过9小时，自动排班从范围中选择班次。在岗满8小时扣除1小时休息，例：11～20点计8小时工作。
- 司机不套用兼职2～9小时限制。管理员在员工页登记司机当月日期和时间，保存后同步月表；取消日期会清除未锁定司机班次，锁定、休假和希望休保留；自动排班保留司机班次，超出当月可出勤范围会提示。
- 点击月表单元格设置班次、希望休、有休、生日假或锁定。需保留的确定班次请锁定。
- 点击自动排班生成候选，再查看冲突检查。未满足条件不会隐藏。
- 支持CSV导出和JSON备份／恢复。旧版已有兼职及司机班次迁移为当月可出勤记录，班表保留。

## 配置规则

- 正社员2月公休9天，其他月份10天；最长连勤5天，尽量2～3天工作后休一天；优先避免晚接早、中接早，优先早早晚或早晚晚。
- 每日早班组合3～4人（早班、日勤及09点前开始的兼职），至少2人在8点前到岗；17～19点至少3人同时在岗。
- 管理者可排早班或07～11点半休。其他正社员每月早班至少4次、晚班至少6次为优化目标，冲突时可安排中班并提示。
- 夜勤每晚1人为最高优先；普通正社员必须两夜连勤后至少两天连休，月末首夜需下月接续；其他规则可放宽并显示冲突，但保留锁定与已批准休假。若无人可安排，明确标为排班未完成。普通正社员下一组首夜尽量距上一组第二夜至少10天，不足时提示。1009每月2次单次夜勤，不连续，每次后两休、间隔至少10天。
- 夜勤按开始日记班，无明け。暂定21～次日06点，含1小时休息，可修改开始时刻。
- 正社员每自然年1天生日假。生日当月自动安排生日当天；年度已在其他日使用时不重复增加。生日假、有休额外增加休息，不抵扣公休。
- 相性不合可设置尽量不同日，或同日早晚分开，作为优化偏好。
- 司机不计入现场人数。仅部分送迎时段缺司机：上午由1003/1004早班兼任，下午缺司机允许空缺，仅显示提示，中班不补位，兼任者仍计现场且不重复计数。
- 送迎覆盖时间在规则页调整，初始上午07:30～13:00、下午16:00～20:00。

## 数据保存

数据仅保存在当前浏览器。换电脑、浏览器或从本地转到在线演示时，需自行备份并恢复。备份包含当前月班表、员工设置及可出勤信息，其他月班表需分别备份。请勿把含真实姓名、生日、排班或相性的信息提交至公开仓库。

删除员工会清理已保存月份的相关记录，可以恢复最近一次删除前的完整快照；恢复会覆盖删除后的修改。跨月信息需在规则页登记，年度生日假检查依据本机保存的月份。

## 文件结构

- `index.html`、`app.js`、`i18n.js`、`styles.css`：网页运行文件，需一起保留。
- `tests/`：规则验证，不影响网页运行。
- `.gitignore`：排除照片、截图、压缩包、备份及本地辅助文件。

安装Node.js后，可在项目根目录运行全部检查：

```sh
node tests/run.cjs
```

## 当前边界

此版本是演示原型。自动排班为启发式搜索，不保证找到完全可行或最优排班。白班暂定早07～16、中09～18（默认加班至19点、负责入浴，工作9小时含加班1小时）、晚11～20，具体休息、访问和入浴任务尚未分配，覆盖按在岗时间计算。尚未加入所在地法定配置校验、账号权限、数据库或多人同步。

中班每人每月最多2次，周日不排中班，同一天最多1人；已有或手动班次违反限制时显示冲突。班表及CSV只标注中班加班，不显示入浴，默认入浴职责保留。

1010与1011均在早班时段实际出勤时，当天不安排中班；以当日班表为准，不仅以可出勤登记为准。

规则优先级：夜勤覆盖及两夜后至少两休、批准休假和兼职可出勤范围优先保证；其次为运营配置；避免晚接早/中接早、公休、最长连勤及普通夜勤间隔为优先优化；早晚班次数、2～3天后休息与相性为参考偏好。兼职取消额外的连勤3天限制，统一按最长5天控制。

管理者可手动选择半休：07:00～11:00，工作4小时、公休计0.5天；计入上午和8点前到岗人数，不计傍晚覆盖。自动排班保留已登记半休，不自动新增半休。

1015为轻作业：保留现有班次和工时，自动排班不改动其班次，不计入早班组合、8点前到岗及17～19点现场覆盖。

中班同时要求：安排前早班组合少于4人，且1010与1011未同时早班时段出勤；每人每月最多2次、周日不排、每天最多1人。
